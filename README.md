# JavaScript Practice Examples

A beginner-friendly collection of practical JavaScript examples maintained by **WebPrims**.

The goal is simple: learn JavaScript by writing, changing, breaking, and fixing real code instead of only memorizing syntax.

## What you'll learn

- Variables and data types
- Operators and conditions
- Loops
- Functions and arrow functions
- Arrays and objects
- DOM selection and manipulation
- Browser events
- Forms and validation
- Local storage
- Fetch API and async/await
- Small browser-based projects

## How to use these examples

Most basic examples can run directly in Node.js:

```bash
node 01-basics/variables.js
```

Browser examples include an `index.html` file. Open that file in your browser and use DevTools to inspect the console and DOM.

## Learning approach

For every example:

1. Run it once as provided.
2. Change values and observe what happens.
3. Add one new feature yourself.
4. Rebuild the example without looking at the original.
5. Use DevTools to understand errors instead of immediately copying a fix.
